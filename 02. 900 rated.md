
## **1. Forked! (Problem 1904A)**

### **Problem Description:**
A chess knight moves in an "L" shape: (a,b) or (b,a) in any direction. Now instead of standard (1,2), you have two integers (a,b). Two kings are placed on a chessboard. Find how many positions a knight can attack such that it can attack **both** kings simultaneously.

### **Concept:**
- Knight can move to 8 positions: (±a, ±b) and (±b, ±a)
- Check all 8 possible positions from king1
- Check if same position can attack king2
- Count unique positions

### **Java Code:**
```java
import java.util.*;

public class Forked {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();
        
        while (t-- > 0) {
            int a = sc.nextInt();
            int b = sc.nextInt();
            int x1 = sc.nextInt();
            int y1 = sc.nextInt();
            int x2 = sc.nextInt();
            int y2 = sc.nextInt();
            
            int[][] moves = {
                {a, b}, {a, -b}, {-a, b}, {-a, -b},
                {b, a}, {b, -a}, {-b, a}, {-b, -a}
            };
            
            Set<String> positions = new HashSet<>();
            
            for (int[] move : moves) {
                int nx = x1 + move[0];
                int ny = y1 + move[1];
                positions.add(nx + "," + ny);
            }
            
            int count = 0;
            for (int[] move : moves) {
                int nx = x2 + move[0];
                int ny = y2 + move[1];
                if (positions.contains(nx + "," + ny)) {
                    count++;
                }
            }
            
            System.out.println(count);
        }
        sc.close();
    }
}
```

## **2. Chemistry (Problem 1883B)**

### **Problem Description:**
You have a string of length n. You can remove at most k characters. After removal, can you rearrange the string to form a palindrome?

### **Concept:**
- In a palindrome, at most one character can have odd frequency
- Count characters with odd frequency
- If `odd_count <= k + 1` (because removing chars can reduce odd_count), it's possible
- Also, n - k >= 1 for at least one character

### **Java Code:**
```java
import java.util.*;

public class Chemistry {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();
        
        while (t-- > 0) {
            int n = sc.nextInt();
            int k = sc.nextInt();
            String s = sc.next();
            
            int[] freq = new int[26];
            for (char c : s.toCharArray()) {
                freq[c - 'a']++;
            }
            
            int oddCount = 0;
            for (int count : freq) {
                if (count % 2 == 1) {
                    oddCount++;
                }
            }
            
            // Remove one from each odd pair
            int requiredRemovals = Math.max(0, oddCount - 1);
            
            if (requiredRemovals <= k && (n - k) >= 1) {
                System.out.println("YES");
            } else {
                System.out.println("NO");
            }
        }
        sc.close();
    }
}
```

## **3. Vasilije in Cacak (Problem 1900A)**

### **Problem Description:**
Given n and k, can we select k distinct integers from 1 to n such that their sum equals x?

### **Concept:**
- Minimum sum with k numbers: 1 + 2 + ... + k = k*(k+1)/2
- Maximum sum with k numbers: n + (n-1) + ... + (n-k+1) = k*(2n - k + 1)/2
- Check if x lies between min and max sum (inclusive)

### **Java Code:**
```java
import java.util.*;

public class VasilijeCacak {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();
        
        while (t-- > 0) {
            long n = sc.nextLong();
            long k = sc.nextLong();
            long x = sc.nextLong();
            
            long minSum = k * (k + 1) / 2;
            long maxSum = k * (2 * n - k + 1) / 2;
            
            if (x >= minSum && x <= maxSum) {
                System.out.println("YES");
            } else {
                System.out.println("NO");
            }
        }
        sc.close();
    }
}
```

We have a timer that starts at b. It increases by 1 each second until it reaches x, then explodes. We have n tools that can reset the timer to min(x, a[i] + current_time). Find maximum time before explosion.

### **Concept:**
- Each tool can add at most (a[i] - 1) seconds when timer is about to reach x
- Greedy: Use the best tool repeatedly
- Answer = b + (sum of (a[i] - 1) for all tools) but bounded

### **Java Code:**
```java

            long[] tools = new long[n];
            long extra = 0;
            
            for (int i = 0; i < n; i++) {
                tools[i] = sc.nextLong();
                extra += Math.min(tools[i], a - 1);
            }
            
            System.out.println(b + extra);
        }

    }
```

### **Problem Description:**
Given n problems with difficulties a[i], you can remove some problems. After removal, for all adjacent pairs, |a[i] - a[j]| ≤ k. Find minimum removals.

- Answer = n - longest_length

```java
import java.util.*;

        Scanner sc = new Scanner(System.in);

                    currentLen++;
                    maxLen = Math.max(maxLen, currentLen);
                } else {
                    currentLen = 1;
                }
```

## **9. Permutation Swap (Problem 1822B)**

### **Problem Description:**
You can swap any two elements if their positions differ by k. Find maximum k such that you can sort the permutation.

### **Concept:**
- For each element at position i, it needs to go to position a[i]
- k must divide |i - a[i]|
- Answer = GCD of all |i - a[i]|

### **Java Code:**
```java
import java.util.*;

public class PermutationSwap {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();
        
        while (t-- > 0) {
            int n = sc.nextInt();
            int[] arr = new int[n + 1];
            
            for (int i = 1; i <= n; i++) {
                arr[i] = sc.nextInt();
            }
            
            int gcd = 0;
            for (int i = 1; i <= n; i++) {
                gcd = computeGCD(gcd, Math.abs(i - arr[i]));
            }
            
            System.out.println(gcd);
        }
        sc.close();
    }
    
    private static int computeGCD(int a, int b) {
        while (b != 0) {
            int temp = b;
            b = a % b;
            a = temp;
        }
        return a;
    }
}
```

## **10. Odd Queries (Problem 1805B)**

### **Problem Description:**
Array of n integers. For each query (l, r, k), if we replace a[l...r] with k, is the sum of whole array odd?

### **Concept:**
- Calculate initial sum parity
- Remove sum of [l, r] parity
- Add parity of k * (r - l + 1)

### **Java Code:**
```java
import java.util.*;

public class OddQueries {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();
        
        while (t-- > 0) {
            int n = sc.nextInt();
            int q = sc.nextInt();
            
            long[] prefix = new long[n + 1];
            for (int i = 1; i <= n; i++) {
                prefix[i] = prefix[i - 1] + sc.nextLong();
            }
            
            while (q-- > 0) {
                int l = sc.nextInt();
                int r = sc.nextInt();
                long k = sc.nextLong();
                
                long total = prefix[n];
                long segmentSum = prefix[r] - prefix[l - 1];
                long newSum = total - segmentSum + (k * (r - l + 1));
                
                if (newSum % 2 == 1) {
                    System.out.println("YES");
                } else {
                    System.out.println("NO");
                }
            }
        }
        sc.close();
    }
}
```

## **12. Mainak and Array (Problem 1726A)**

### **Problem Description:**
Given an array, you can rotate any subarray in one operation. Find maximum possible value of a[n] - a[1] after at most one operation.

### **Concept:**
- Either don't rotate: ans = a[n-1] - a[0]
- Rotate so that largest element becomes last: ans = max(a[i]) - a[0]
- Rotate so that smallest element becomes first: ans = a[n-1] - min(a[i])
- Rotate entire array: ans = a[n-2] - a[0] or a[n-1] - a[1]
- Take maximum of all cases

### **Java Code:**
```java
import java.util.*;

public class MainakAndArray {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();
        
        while (t-- > 0) {
            int n = sc.nextInt();
            int[] arr = new int[n];
            
            for (int i = 0; i < n; i++) {
                arr[i] = sc.nextInt();
            }
            
            if (n == 1) {
                System.out.println(0);
                continue;
            }
            
            int ans = arr[n - 1] - arr[0];
            
            // Rotate so largest becomes last
            for (int i = 0; i < n - 1; i++) {
                ans = Math.max(ans, arr[i] - arr[0]);
            }
            
            // Rotate so smallest becomes first
            for (int i = 1; i < n; i++) {
                ans = Math.max(ans, arr[n - 1] - arr[i]);
            }
            
            // Adjacent differences
            for (int i = 1; i < n; i++) {
                ans = Math.max(ans, arr[i - 1] - arr[i]);
            }
            
            System.out.println(ans);
        }
        sc.close();
    }
}
```

## **13. NIT Destroys the Universe (Problem 1696A)**

### **Problem Description:**
Given an array, in one operation you can choose l, r and set all elements in [l, r] to MEX of that subarray. Find minimum operations to make all elements zero.

### **Concept:**
- If all elements are already 0 → 0 operations
- If array has contiguous non-zero segment → 1 operation
- If non-zero elements are in multiple segments → 2 operations

### **Java Code:**
```java
import java.util.*;

public class NITDestroysUniverse {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();
        
        while (t-- > 0) {
            int n = sc.nextInt();
            int[] arr = new int[n];
            boolean hasZero = false;
            
            for (int i = 0; i < n; i++) {
                arr[i] = sc.nextInt();
                if (arr[i] == 0) hasZero = true;
            }
            
            // Check if all are zero
            boolean allZero = true;
            for (int num : arr) {
                if (num != 0) {
                    allZero = false;
                    break;
                }
            }
            
            if (allZero) {
                System.out.println(0);
                continue;
            }
            
            // Count non-zero segments
            int segments = 0;
            int i = 0;
            while (i < n) {
                if (arr[i] != 0) {
                    segments++;
                    while (i < n && arr[i] != 0) {
                        i++;
                    }
                } else {
                    i++;
                }
            }
            
            if (segments == 1) {
                System.out.println(1);
            } else {
                System.out.println(2);
            }
        }
        sc.close();
    }
}
```

## **15. Make It Increasing (Problem 1665A)**

### **Problem Description:**
Given array a, in one operation choose i and divide a[i] by 2 (floor). Find minimum operations to make array strictly increasing.

### **Concept:**
- Process from right to left
- While current >= next, divide by 2
- If becomes 0 and still >= next → impossible

```java
import java.util.*;

            boolean possible = true;
            
            for (int i = n - 2; i >= 0; i--) {
                while (arr[i] >= arr[i + 1] && arr[i] > 0) {
                    arr[i] /= 2;
                    operations++;
                }
                if (arr[i] >= arr[i + 1]) {
                    possible = false;
                    break;
                }
            }
            
            System.out.println(possible ? operations : -1);
        }
```

## **17. Array Cloning Technique (Problem 1660B)**

### **Problem Description:**
You have an array. In one operation, you can clone the entire array or swap any two elements. Find minimum operations to make all elements equal.

### **Concept:**
- Find frequency of most frequent element (maxFreq)
- Clone operation doubles the count of that element
- Number of clones = ceil(log2(n/maxFreq))
- Plus (n - maxFreq) swaps

### **Java Code:**
```java
import java.util.*;

public class ArrayCloningTechnique {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();
        
        while (t-- > 0) {
            int n = sc.nextInt();
            Map<Integer, Integer> freq = new HashMap<>();
            int maxFreq = 0;
            
            for (int i = 0; i < n; i++) {
                int x = sc.nextInt();
                freq.put(x, freq.getOrDefault(x, 0) + 1);
                maxFreq = Math.max(maxFreq, freq.get(x));
            }
            
            int clones = 0;
            int current = maxFreq;
            while (current < n) {
                clones++;
                clones += Math.min(current, n - current);
                current *= 2;
            }
            
            System.out.println(clones);
        }
        sc.close();
    }
}
```

## **21. Make it Divisible by 25 (Problem 1593A)**

### **Problem Description:**
Given a number as string, remove minimum digits so remaining number (keeping order) is divisible by 25.

### **Concept:**
- Numbers divisible by 25 end with 00, 25, 50, or 75
- Find last occurrence of 0 then another 0 before it
- Or 2 then 5, 5 then 0, 7 then 5
- Take minimum removals

### **Java Code:**
```java
import java.util.*;

public class DivisibleBy25 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();
        
        while (t-- > 0) {
            String s = sc.next();
            String[] patterns = {"00", "25", "50", "75"};
            int ans = s.length();
            
            for (String pattern : patterns) {
                ans = Math.min(ans, findRemovals(s, pattern));
            }
            
            System.out.println(ans);
        }
        sc.close();
    }
    
    private static int findRemovals(String s, String pattern) {
        int i = s.length() - 1;
        int count = 0;
        
        // Find last digit of pattern
        while (i >= 0 && s.charAt(i) != pattern.charAt(1)) {
            i--;
            count++;
        }
        
        if (i < 0) return s.length();
        i--;
        
        // Find first digit of pattern
        while (i >= 0 && s.charAt(i) != pattern.charAt(0)) {
            i--;
            count++;
        }
        
        if (i < 0) return s.length();
        return count;
    }
}
```

## **22. Luntik and Subsequences (Problem 1582B)**

### **Problem Description:**
Given array, count how many subsequences have sum = total_sum - 1.

### **Concept:**
- Let count of ones = c1, count of zeros = c0
- Each subsequence must include all ones except one
- Formula: c1 * (2^c0)

### **Java Code:**
```java
import java.util.*;

public class LuntikSubsequences {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();
        
        while (t-- > 0) {
            int n = sc.nextInt();
            long ones = 0, zeros = 0;
            
            for (int i = 0; i < n; i++) {
                int x = sc.nextInt();
                if (x == 1) ones++;
                if (x == 0) zeros++;
            }
            
            System.out.println(ones * (1L << zeros));
        }
        sc.close();
    }
}
```

## **24. Exciting Bets (Problem 1543A)**

### **Problem Description:**
Given a and b, you can add 1 or subtract 1 from both in one move. Find maximum possible gcd after any number of moves and minimum moves to achieve it.

### **Concept:**
- Maximum gcd = |a - b|
- If a = b, gcd can be arbitrarily large (answer 0 0)
- Minimum moves = min(a % diff, diff - (a % diff))

### **Java Code:**
```java
import java.util.*;

public class ExcitingBets {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();
        
        while (t-- > 0) {
            long a = sc.nextLong();
            long b = sc.nextLong();
            
            if (a == b) {
                System.out.println("0 0");
                continue;
            }
            
            long diff = Math.abs(a - b);
            long moves = Math.min(a % diff, diff - (a % diff));
            
            System.out.println(diff + " " + moves);
        }
        sc.close();
    }
}
```

- Maximum = sum of ceil(a[i]/x)
- Minimum = ceil(sum(a[i])/x)

```java
import java.util.*;

                long val = sc.nextLong();
                sum += val;
```

## **28. Sum of Medians (Problem 1440B)**

### **Problem Description:**
Given 2k numbers, split into k groups of 2, and sum the minimum of each group. Maximize this sum.

### **Concept:**
- Sort array in descending order
- Take every (k+1)-th element from the end
- Or use formula: sum of elements at positions n - k, n - 2k, n - 3k...

### **Java Code:**
```java
import java.util.*;

public class SumOfMedians {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();
        
        while (t-- > 0) {
            int n = sc.nextInt();
            int k = sc.nextInt();
            int total = n * k;
            long[] arr = new long[total];
            
            for (int i = 0; i < total; i++) {
                arr[i] = sc.nextLong();
            }
            
            long sum = 0;
            int mid = (n + 1) / 2;
            int pos = total - mid;
            
            for (int i = 0; i < k; i++) {
                sum += arr[pos];
                pos -= mid;
            }
            
            System.out.println(sum);
        }
        sc.close();
    }
}
```

## **29. Three Indices (Problem 1385B)**

### **Problem Description:**
Find three indices i < j < k such that a[j] > a[i] and a[j] > a[k].

### **Concept:**
- For each index j, find smaller element on left and smaller on right
- Use prefix min and suffix min

### **Java Code:**
```java
import java.util.*;

public class ThreeIndices {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();
        
        while (t-- > 0) {
            int n = sc.nextInt();
            int[] arr = new int[n];
            
            for (int i = 0; i < n; i++) {
                arr[i] = sc.nextInt();
            }
            
            int[] leftMin = new int[n];
            int[] rightMin = new int[n];
            
            leftMin[0] = 0;
            for (int i = 1; i < n; i++) {
                leftMin[i] = (arr[i] < arr[leftMin[i - 1]]) ? i : leftMin[i - 1];
            }
            
            rightMin[n - 1] = n - 1;
            for (int i = n - 2; i >= 0; i--) {
                rightMin[i] = (arr[i] < arr[rightMin[i + 1]]) ? i : rightMin[i + 1];
            }
            
            boolean found = false;
            for (int j = 1; j < n - 1; j++) {
                if (arr[leftMin[j - 1]] < arr[j] && arr[rightMin[j + 1]] < arr[j]) {
                    System.out.println("YES");
                    System.out.println((leftMin[j - 1] + 1) + " " + (j + 1) + " " + (rightMin[j + 1] + 1));
                    found = true;
                    break;
                }
            }
            
            if (!found) {
                System.out.println("NO");
            }
        }
        sc.close();
    }
}
```

## **30. 01 Game (Problem 1367A)**

### **Problem Description:**
Two players remove "01" or "10" substrings alternately. Player who can't move loses. Who wins?

### **Concept:**
- Count of zeros and ones
- Minimum of zeros and ones determines moves
- If min(count0, count1) is odd → Alice wins
- Else Bob wins

### **Java Code:**
```java
import java.util.*;

public class ZeroOneGame {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();
        
        while (t-- > 0) {
            String s = sc.next();
            int zeros = 0, ones = 0;
            
            for (char c : s.toCharArray()) {
                if (c == '0') zeros++;
                else ones++;
            }
            
            int moves = Math.min(zeros, ones);
            if (moves % 2 == 1) {
                System.out.println("DA"); // Alice wins
            } else {
                System.out.println("NET"); // Bob wins
            }
        }
        sc.close();
    }
}
```

## **31. Multiply by 2, divide by 6 (Problem 1374B)**

### **Problem Description:**
Given n, you can multiply by 2 or divide by 6 (if divisible). Find minimum operations to make n = 1, else -1.

### **Concept:**
- Check if n = 2^a * 3^b
- If other prime factors exist → -1
- If a > b → -1
- Operations = b + (b - a)

### **Java Code:**
```java
import java.util.*;

public class MultiplyDivide {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();
        
        while (t-- > 0) {
            long n = sc.nextLong();
            int count2 = 0, count3 = 0;
            
            while (n % 2 == 0) {
                n /= 2;
                count2++;
            }
            
            while (n % 3 == 0) {
                n /= 3;
                count3++;
            }
            
            if (n != 1 || count2 > count3) {
                System.out.println(-1);
            } else {
                System.out.println((count3 - count2) + count3);
            }
        }
        sc.close();
    }
}
```
