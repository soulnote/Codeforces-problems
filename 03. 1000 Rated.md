## **1. Swap and Delete (Problem 1913B)**

### **Problem Description:**
Binary string s. In one operation: delete one character (cost 1) OR swap any two characters (cost 0). Find minimum cost to make string "good" (no character equals its position index? Actually: for all i, s[i] != s[i+1] after operations). Wait - let me clarify: You can swap (free) or delete (cost 1). Make string such that no two adjacent chars are equal.

### **Concept:**
- After swaps, you can rearrange freely (since swaps are free)
- So you can arrange any order of remaining characters
- Need alternating pattern (0101... or 1010...)
- Let count0 = zeros, count1 = ones
- If |count0 - count1| ≤ 1 → cost 0 (can alternate perfectly)
- Else need to delete extra characters: cost = |count0 - count1| - 1

### **Java Code:**
```java
import java.util.*;

public class SwapAndDelete {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();
        
        while (t-- > 0) {
            String s = sc.next();
            int zeros = 0, ones = 0;
            for (char c : s.toCharArray()) {
                if (c == '0') zeros++;
                else ones++;
            }
            
            int ans = Math.min(zeros, ones);
            System.out.println(ans);
        }
        sc.close();
    }
}
```

## **2. Raspberries (Problem 1883C)**

### **Problem Description:**
Given array a and number k (k is 2, 3, 4, or 5). In one operation, add 1 to any element. Find minimum operations so product of all elements divisible by k.

### **Concept:**
- For k = 2, 3, 5: need at least one element divisible by k
- For k = 4: need either one element divisible by 4, or two elements divisible by 2
- Check each case and take minimum

### **Java Code:**
```java
import java.util.*;

public class Raspberries {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();
        
        while (t-- > 0) {
            int n = sc.nextInt();
            int k = sc.nextInt();
            int[] arr = new int[n];
            
            for (int i = 0; i < n; i++) {
                arr[i] = sc.nextInt();
            }
            
            if (k == 2 || k == 3 || k == 5) {
                int minOps = k;
                for (int num : arr) {
                    if (num % k == 0) minOps = 0;
                    minOps = Math.min(minOps, (k - (num % k)) % k);
                }
                System.out.println(minOps);
            } 
            else { // k == 4
                int minOps = 3;
                int countEven = 0;
                for (int num : arr) {
                    if (num % 4 == 0) minOps = 0;
                    if (num % 2 == 0) countEven++;
                    minOps = Math.min(minOps, (4 - (num % 4)) % 4);
                }
                if (countEven >= 2) minOps = Math.min(minOps, 0);
                else if (countEven == 1) minOps = Math.min(minOps, 1);
                System.out.println(minOps);
            }
        }
        sc.close();
    }
}
```

## **3. Helmets in Night Light (Problem 1876A)**

### **Problem Description:**
n people, each needs a helmet. Person 0 can share to others with cost p per person. Person i (1..n) when gets helmet, can share to others at cost a[i] per person, but can only share to b[i] people. Find minimum cost to give helmet to all.

### **Concept:**
- Sort people by sharing cost a[i]
- Greedy: use cheapest sharers first
- Person 0 shares at cost p to everyone initially

### **Java Code:**
```java
import java.util.*;

public class HelmetsNightLight {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();
        
        while (t-- > 0) {
            int n = sc.nextInt();
            int p = sc.nextInt();
            
            int[] a = new int[n];
            int[] b = new int[n];
            
            for (int i = 0; i < n; i++) a[i] = sc.nextInt();
            for (int i = 0; i < n; i++) b[i] = sc.nextInt();
            
            Integer[] indices = new Integer[n];
            for (int i = 0; i < n; i++) indices[i] = i;
            Arrays.sort(indices, (x, y) -> a[x] - a[y]);
            
            long cost = p; // first person
            int remaining = n - 1;
            int idx = 0;
            
            while (remaining > 0 && idx < n) {
                int person = indices[idx];
                int shareCost = a[person];
                int canShare = b[person];
                
                if (shareCost >= p) break;
                
                int take = Math.min(canShare, remaining);
                cost += (long) take * shareCost;
                remaining -= take;
                idx++;
            }
            
            cost += (long) remaining * p;
            System.out.println(cost);
        }
        sc.close();
    }
}
```

## **4. Olya and Game with Arrays (Problem 1860A)**

### **Problem Description:**
n arrays. In one move, take any element from any array and move to any other array. After moves, each array must have at least 2 elements and all arrays must have same sum. Find if possible.

### **Concept:**
- Total sum must be divisible by n
- Each array needs at least 2 elements
- Minimal element in each array matters

### **Java Code:**
```java
import java.util.*;

public class OlyaAndGame {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();
        
        while (t-- > 0) {
            int n = sc.nextInt();
            List<List<Long>> arrays = new ArrayList<>();
            long totalSum = 0;
            int totalElements = 0;
            
            for (int i = 0; i < n; i++) {
                int m = sc.nextInt();
                totalElements += m;
                List<Long> arr = new ArrayList<>();
                for (int j = 0; j < m; j++) {
                    long val = sc.nextLong();
                    arr.add(val);
                    totalSum += val;
                }
                Collections.sort(arr);
                arrays.add(arr);
            }
            
            if (totalSum % n != 0) {
                System.out.println("No");
                continue;
            }
            
            long target = totalSum / n;
            boolean possible = true;
            
            for (int i = 0; i < n; i++) {
                List<Long> arr = arrays.get(i);
                long sum = 0;
                for (long val : arr) sum += val;
                long needed = target - (sum - arr.get(0));
                if (!arr.contains(needed)) {
                    possible = false;
                    break;
                }
            }
            
            System.out.println(possible ? "Yes" : "No");
        }
        sc.close();
    }
}
```

### **Problem Description:**
n monsters with health a[i]. Each attack reduces health of all alive monsters by 1, but if a monster's health becomes <= 0, it dies and doesn't get further damage. Find order monsters die.

### **Concept:**
- Sort by health % k, then by original index
- Or simulate with priority queue

### **Java Code:**
```java
import java.util.*;

public class Monsters {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();

            int n = sc.nextInt();

            Integer[] indices = new Integer[n];

                arr[i] = sc.nextInt();
                indices[i] = i;
            }
            
            Arrays.sort(indices, (x, y) -> {
                int modX = arr[x] % k;
                int modY = arr[y] % k;
                if (modX == 0) modX = k;
                if (modY == 0) modY = k;
                if (modX != modY) return modY - modX;
                return x - y;
            });
            
            for (int idx : indices) {
                System.out.print((idx + 1) + " ");
            }
            System.out.println();
        }
        sc.close();
    }
```

## **6. Ski Resort (Problem 1840C)**

### **Problem Description:**
Given array a, find number of subarrays of length at least k where all elements ≤ q.

### **Concept:**
- Find consecutive segments where all elements ≤ q
- For segment of length len, number of valid subarrays = (len - k + 1) * (len - k + 2) / 2 if len ≥ k

### **Java Code:**
```java
import java.util.*;

public class SkiResort {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();
        
        while (t-- > 0) {
            int n = sc.nextInt();
            int k = sc.nextInt();
            int q = sc.nextInt();
            int[] arr = new int[n];
            
            for (int i = 0; i < n; i++) {
                arr[i] = sc.nextInt();
            }
            
            long ans = 0;
            int len = 0;
            
            for (int i = 0; i < n; i++) {
                if (arr[i] <= q) {
                    len++;
                } else {
                    if (len >= k) {
                        long m = len - k + 1;
                        ans += m * (m + 1) / 2;
                    }
                    len = 0;
                }
            }
            
            if (len >= k) {
                long m = len - k + 1;
                ans += m * (m + 1) / 2;
            }
            
            System.out.println(ans);
        }
        sc.close();
    }
}
```

### **Problem Description:**
Given two arrays a and b, merge them into one array c. You can only take from front of either array. Find lexicographically smallest c.

- If equal, need to look ahead

```java
import java.util.*;

                } else {
                    result.add(b[j++]);
                }
            }
            
            while (i < n) result.add(a[i++]);
            while (j < m) result.add(b[j++]);
            
            for (int num : result) {
                System.out.print(num + " ");
            }
```

## **8. Distinct Split (Problem 1791C)**

### **Problem Description:**
Split binary string into two non-empty parts, maximize f(prefix) + f(suffix) where f(s) = number of distinct characters.

### **Concept:**
- Try all split positions
- f(s) = 1 if all same, 2 if mixed

### **Java Code:**
```java
import java.util.*;

public class DistinctSplit {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();
        
        while (t-- > 0) {
            int n = sc.nextInt();
            String s = sc.next();
            
            int[] prefix = new int[n];
            int[] suffix = new int[n];
            
            boolean[] seen = new boolean[26];
            int count = 0;
            for (int i = 0; i < n; i++) {
                if (!seen[s.charAt(i) - 'a']) {
                    seen[s.charAt(i) - 'a'] = true;
                    count++;
                }
                prefix[i] = count;
            }
            
            seen = new boolean[26];
            count = 0;
            for (int i = n - 1; i >= 0; i--) {
                if (!seen[s.charAt(i) - 'a']) {
                    seen[s.charAt(i) - 'a'] = true;
                    count++;
                }
                suffix[i] = count;
            }
            
            int max = 0;
            for (int i = 0; i < n - 1; i++) {
                max = Math.max(max, prefix[i] + suffix[i + 1]);
            }
            
            System.out.println(max);
        }
        sc.close();
    }
}
```

### **Problem Description:**
n players with powers a[i]. Team power = min(power) * number of players. Find max total teams where each team power > D.

- Greedy: take strongest with weakest

```java
            int count = 1;

                    teams++;
                    j--;
                    if (j >= i) {
                        current = arr[j];
                        count = 1;

                    i++;
                    count++;
                    current = arr[j] * count;
                }
            }
            
            System.out.println(teams);
        }

    }
}
```

```java
            }
            
            Arrays.sort(indices, (x, y) -> Long.compare(a[y], a[x]));
            
            long[] pos = new long[n];
            long ans = 0;
            long left = -1, right = 1;
            
            for (int idx : indices) {
                if (Math.abs(left) <= Math.abs(right)) {
                    pos[idx] = left;
                    ans += a[idx] * Math.abs(left);
                    left--;
                } else {
                    pos[idx] = right;
                    ans += a[idx] * Math.abs(right);
                    right++;
                }
            }
            
            System.out.println(ans * 2);
            System.out.print("0 ");
            for (int i = 0; i < n; i++) {
                System.out.print(pos[i] + " ");
            }
            System.out.println();
        }
        sc.close();
    }
}
```

## **20. MEXor Mixup (Problem 1567B)**

### **Problem Description:**
Find smallest array such that MEX = a and XOR of all elements = b.

- XOR of first a numbers (0 to a-1) = x
- If x == b, answer = a
- Else if (x ^ b) != a, answer = a + 1

```java
        }
        
        while (t-- > 0) {
            int a = sc.nextInt();
            int b = sc.nextInt();
            
            int xor = xorTill[a - 1];
            
            if (xor == b) {
                System.out.println(a);
            } else if ((xor ^ b) != a) {
                System.out.println(a + 1);
            } else {
```

## **21. Double-ended Strings (Problem 1506B)**

### **Problem Description:**
Two strings, remove prefix/suffix characters to make them equal. Find min removals.

### **Concept:**
- Find longest common substring (not subsequence)
- Removals = len1 + len2 - 2 * LCS_length

### **Java Code:**
```java
import java.util.*;

public class DoubleEndedStrings {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();
        
        while (t-- > 0) {
            String a = sc.next();
            String b = sc.next();
            
            int maxMatch = 0;
            
            for (int i = 0; i < a.length(); i++) {
                for (int j = 0; j < b.length(); j++) {
                    int k = 0;
                    while (i + k < a.length() && j + k < b.length() && 
                           a.charAt(i + k) == b.charAt(j + k)) {
                        k++;
                    }
                    maxMatch = Math.max(maxMatch, k);
                }
            }
            
            int ans = a.length() + b.length() - 2 * maxMatch;
            System.out.println(ans);
        }
        sc.close();
    }
}
```

## **23. Different Divisors (Problem 1474B)**

### **Problem Description:**
Find smallest number with exactly 4 divisors and difference between divisors ≥ d.

### **Concept:**
- Need product of two primes p and q
- p ≥ d + 1, q ≥ p + d

### **Java Code:**
```java
import java.util.*;

public class DifferentDivisors {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();
        
        boolean[] isPrime = sieve(100000);
        
        while (t-- > 0) {
            int d = sc.nextInt();
            
            int p = d + 1;
            while (!isPrime[p]) p++;
            int q = p + d;
            while (!isPrime[q]) q++;
            
            System.out.println((long) p * q);
        }
        sc.close();
    }
    
    private static boolean[] sieve(int n) {
        boolean[] prime = new boolean[n + 1];
        Arrays.fill(prime, true);
        prime[0] = prime[1] = false;
        for (int i = 2; i * i <= n; i++) {
            if (prime[i]) {
                for (int j = i * i; j <= n; j += i) {
                    prime[j] = false;
                }
            }
        }
        return prime;
    }
}
```

Number is fair if divisible by each of its non-zero digits. Find smallest fair number ≥ n.

- 2520 is LCM of 1-9

```java
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();

            long n = sc.nextLong();

                    System.out.println(i);
                    break;
                }
            }

            }
            temp /= 10;
        }
        return true;
    }
```

## **29. Johnny and Ancient Computer (Problem 1362A)**

### **Problem Description:**
Convert a to b by multiplying/dividing by 2, 4, or 8. Find min operations.

### **Concept:**
- If a < b, multiply; if a > b, divide
- Check if ratio is power of 2
- Operations = floor(log2(ratio)/3) with ceiling

### **Java Code:**
```java
import java.util.*;

    public static void main(String[] args) {

            long a = sc.nextLong();
            long b = sc.nextLong();

                a = b;
                b = temp;

            if ((ratio & (ratio - 1)) != 0) {
                System.out.println(-1);
                continue;
            }

            while (ratio >= 8) {
                ratio /= 8;
                ops++;
            }

        }
```
