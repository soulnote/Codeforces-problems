## **2. Quests (Problem 1914C)**

### **Problem Description:**
You have n quests. First time doing quest i gives a[i] experience, repeats give b[i]. You can do k quests total. You can only unlock next quest after completing previous. Max experience.

### **Concept:**
- Prefix sum of a[i]
- Track max b[i] so far
- For each i (1..min(n,k)), total = sumA[i-1] + (k-i) * maxB

### **Java Code:**
```java
import java.util.*;

public class Quests {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();
        while (t-- > 0) {
            int n = sc.nextInt();
            int k = sc.nextInt();
            int[] a = new int[n];
            int[] b = new int[n];
            for (int i = 0; i < n; i++) a[i] = sc.nextInt();
            for (int i = 0; i < n; i++) b[i] = sc.nextInt();
            
            long sum = 0, maxB = 0, ans = 0;
            for (int i = 0; i < Math.min(n, k); i++) {
                sum += a[i];
                maxB = Math.max(maxB, b[i]);
                ans = Math.max(ans, sum + (k - i - 1) * maxB);
            }
            System.out.println(ans);
        }
    }
}
```

## **3. Collecting Game (Problem 1904C)**

### **Problem Description:**
Given array, you can collect numbers less than or equal to current score, add them to score. Start with 0. Find max score.

### **Concept:**
- Sort array
- Greedy: take all possible, then move to next

### **Java Code:**
```java
import java.util.*;

public class CollectingGame {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();
        while (t-- > 0) {
            int n = sc.nextInt();
            Long[] arr = new Long[n];
            for (int i = 0; i < n; i++) arr[i] = sc.nextLong();
            Arrays.sort(arr);
            
            long sum = 0;
            int cnt = 0;
            for (int i = 0; i < n; i++) {
                if (arr[i] <= sum) {
                    sum += arr[i];
                    cnt++;
                } else {
                    break;
                }
            }
            System.out.println(cnt);
        }
    }
}
```

### **Sample Detailed Solution for #4 Yarik and Array**

```java
import java.util.*;

public class YarikAndArray {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();
        while (t-- > 0) {
            int n = sc.nextInt();
            int[] arr = new int[n];
            for (int i = 0; i < n; i++) arr[i] = sc.nextInt();
            
            long maxSum = arr[0], currentSum = arr[0];
            for (int i = 1; i < n; i++) {
                if ((arr[i] % 2 == 0 && arr[i-1] % 2 != 0) || 
                    (arr[i] % 2 != 0 && arr[i-1] % 2 == 0)) {
                    currentSum = Math.max(arr[i], currentSum + arr[i]);
                } else {
                    currentSum = arr[i];
                }
                maxSum = Math.max(maxSum, currentSum);
            }
            System.out.println(maxSum);
        }
    }
}
```
